# Case 02 — Messy data quality

**Case ID:** SYNTH-DATA-002  
**Input:** `sales-data.csv` (24 data rows, weekly orders January to May 2026)

An operations analyst pasted order lines from several sources into one sheet. Some rows were entered twice, a few amounts are missing or typed as text, a return was recorded as a negative amount, and dates use three different formats. The analyst wants insight, but also needs to know what to clean first.

**Suggested prompt:** Analyze my sales spreadsheet, highlight trends and anomalies, and create a dashboard. Tell me what data problems I need to fix.
