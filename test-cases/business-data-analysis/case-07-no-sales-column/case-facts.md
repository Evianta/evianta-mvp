# Case 07 — No sales column

**Case ID:** SYNTH-DATA-007  
**Input:** `inventory-counts.csv` (6 rows)

A warehouse supervisor uploads monthly stock-on-hand counts (`month, product, warehouse, stock_on_hand`) by mistake and asks for a sales analysis. The file has no sales, revenue or amount column.

**Suggested prompt:** Analyze my sales spreadsheet, highlight trends and anomalies, and create a dashboard.

This is the negative case: the system must say the file is not usable for sales analysis.
